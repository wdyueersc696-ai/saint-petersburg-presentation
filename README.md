# Санкт-Петербург: туризм и бизнес гостеприимства

Интерактивная браузерная презентация: 16 слайдов, анимация, историческое видео со звуком и полный текст выступления в PDF.

Для просмотра опубликованной страницы ничего устанавливать не нужно. Откройте ссылку в современном браузере и нажмите «Вступление» для воспроизведения видео со звуком.

По умолчанию включена плавная прокрутка. Кнопка «Слайды» переключает в обычный режим показа, «Скролл» возвращает прокрутку. Стрелки и пробел переходят к следующему экрану; «Текст» открывает заметки и PDF; «Оглавление» и боковые метки выбирают раздел.

Источники и лицензии изображений доступны через кнопку «Источники и материалы»; источники видеоролика находятся в [intro/CREDITS.md](intro/CREDITS.md). Лицензии библиотек и шрифтов сохранены рядом с файлами.

Материалы являются учебным анализом. Годовые показатели относятся к 2025 году.
